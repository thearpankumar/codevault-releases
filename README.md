# Code Vault update feed

Machine-readable update metadata for Code Vault, published by the release pipeline of the student app
(one folder per release tag: Velopack `*-full.nupkg` packages, signed `releases.<rid>-<channel>.json`
feeds, signed `manifest.json`). Served via GitHub Pages; used by the Code Vault server and the in-app
updater. Installers are on the [Releases page](https://github.com/thearpankumar/codevault-releases/releases).
Do not edit by hand.
